# Note Viewer — sample notes / 노트 뷰어 예시 노트

Sample PDF notes for trying the GitHub feature of **Note Viewer** (노트 뷰어), an Android app for reading notes backed up as PDFs.

In the app: **Settings → GitHub → Add a GitHub repository** → paste `github.com/lunarjg/noteviewer-samples`.
The PDFs in this repository (and in its latest release) appear in the library; when a file changes here, the app shows the new version.

앱에서 **설정 → GitHub → GitHub 저장소 추가** → `github.com/lunarjg/noteviewer-samples` 를 붙여 넣으면 이 저장소의 PDF(와 최신 릴리스의 PDF)가 서재에 보입니다.

- `biology/week1-cells.pdf` — lecture notes
- `planner/weekly-planner.pdf` — a planner
- `vocabulary.pdf` — try memorize mode (red and blue pens)

These files are samples made for the app and may be used freely (CC0).
